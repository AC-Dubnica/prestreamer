# Keyboard shortcuts

The keys work from any tab (except where noted) as long as you are not typing in a text box.

| Key | What it does |
| --- | --- |
| **→**, **↓** or **Space** | Next slide |
| **←** or **↑** | Previous slide |
| **Space** (while a video is on) | Play or pause the video, instead of next slide |
| **Esc** | Take the slide off every screen |
| **A** | Open the announcement window |
| **L** | Show or hide the logo on every screen |
| **Cmd + 1 … 9** (Ctrl on Windows and Linux) | Jump to the 1st … 9th item of the run sheet |
| **↑ / ↓** (Songs tab) | Walk through the song list |
| **Cmd/Ctrl + Z**, **Cmd/Ctrl + Shift + Z** (Mixer tab) | Undo and redo a mixer change |
| **Cmd/Ctrl + Enter** (in the announcement text) | Show the message |
| **Esc** (in a window) | Close it without applying |

In the Present tab, the grip (⠿) of a screen can be moved with **↑ ↓** to reorder screens; in the Mixer the grip of a strip or effect card moves with **← →**.
