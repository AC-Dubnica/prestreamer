# Klávesové skratky

Klávesy fungujú z ktorejkoľvek karty (okrem miest, kde je uvedené inak), kým nepíšete do textového poľa.

| Kláves | Čo robí |
| --- | --- |
| **→**, **↓** alebo **medzerník** | Ďalšia snímka |
| **←** alebo **↑** | Predchádzajúca snímka |
| **Medzerník** (keď je zapnuté video) | Prehrá alebo pozastaví video namiesto ďalšej snímky |
| **Esc** | Odstráni snímku zo všetkých obrazoviek |
| **A** | Otvorí okno oznamu |
| **L** | Zobrazí alebo skryje logo na každej obrazovke |
| **Cmd + 1 … 9** (Ctrl vo Windowse a Linuxe) | Skočí na 1. … 9. položku programu |
| **↑ / ↓** (karta Piesne) | Pohyb v zozname piesní |
| **Cmd/Ctrl + Z**, **Cmd/Ctrl + Shift + Z** (karta Mixér) | Späť a znova pre zmenu v mixéri |
| **Cmd/Ctrl + Enter** (v texte oznamu) | Zobrazí správu |
| **Esc** (v okne) | Zatvorí ho bez použitia zmien |

Na karte Premietanie možno úchyt (⠿) obrazovky posúvať klávesmi **↑ ↓** a meniť tak poradie obrazoviek; v Mixéri sa úchyt kanála alebo karty efektu posúva klávesmi **← →**.
